# 复现与判定口径

## 1. 环境

| 项 | 要求 |
|---|---|
| apktool | 3.0.3（`apktool d` 解码 smali + 资源） |
| python3 | 3.8+（仅标准库） |
| 内存 | 解码 25–30MB 的 SystemUI 包建议 `JAVA_OPTS=-Xmx3500m` |

脚本默认工作目录为自身所在目录的上一级（即仓库根），可用环境变量 `DIFF_BASE` 覆盖。

## 2. 用法

```bash
export APK_ORIG="/path/系统界面组件_18.3.2.57.0_anti.apk"
export APK_MOD="/path/七彩祥云_圆.apk"

# 1) 解码 + 生成类/资源清单
bash scripts/run_diff.sh

# 2) 方法级归一化 diff
python3 scripts/analyze_methods.py     # → code_summary.md

# 3) 资源集合对比
python3 scripts/vals_compare.py        # → res_summary.md

# 4) ZIP 条目级对比（不依赖 apktool）
python3 scripts/zipdiff.py "$APK_ORIG" "$APK_MOD"   # → zip_layer.txt
```

产物：

| 文件 | 内容 |
|---|---|
| `dec_orig/` `dec_mod/` | apktool 解码态 |
| `orig_smali.list` `mod_smali.list` | 类文件清单 |
| `new_classes.txt` `del_classes.txt` `differ_classes.txt` | 新增/删除/内容不同的类 |
| `code_summary.md` | 真实改动类、方法/字段明细、注入热点 |
| `rdiff/orig.list` `mod.list` `res_new.txt` `res_del.txt` `res_mod.txt` `manifest.diff` | 资源与 Manifest 差异 |
| `res_summary.md` | values 值变化、新增键、layout 自定义 View 变化 |
| `zip_layer.txt` | ZIP 条目新增/删除/变化 |

## 3. 噪声判定口径

smali 归一化规则（`analyze_methods.py`）：

1. 删除 `nop`（dex 对齐填充）
2. 删除 `.source`（go/retraceme 生成的方法哈希）
3. 删除 `.line`（行号表）
4. 删除 `.registers` / `.locals`（寄存器分配差异）
5. 寄存器重编号：`\b[vp]\d+\b` → `R`
6. 标签重命名：`:[A-Za-z0-9_$-]+` → `:L`
7. `const-string/jumbo` → `const-string`（字符串池 >65535 时的编码差异）
8. 字段静态初值：去掉 `= null/false/true/0x0/数字`

资源归一化规则（`vals_compare.py`）：

1. values 用 `(type,name) -> value` 映射比较，不用文本 diff（apktool 输出顺序不稳定）
2. 颜色归一：`#RRGGBB` 与 `#ffRRGGBB` 视为同值；复合值里的 `#ffRRGGBB` 也归一
3. 尺寸归一：`24.0dp` == `24dp`

判为噪声、不计入「真实改动」的项：

- `androidx` / `miuix` / `kotlin` / `onetrack` 等第三方库类的 ±1 指令差异
- `public.xml` 的 ID 后移
- `values/arrays.xml` 的 `#ffXXXXXX → #XXXXXX` 格式化
- 同一个类在 `classes.dex` 与 `classes2.dex` 之间迁移（一增一删）

## 4. 已知限制

- `apktool d` 会把 APK 根目录的 `blackscreen/*.xml` 解码到 `res/drawable/` 同名文件，因此「res 新增 72」里包含这 42 个状态矢量；按 ZIP 层统计则是 42 个 `blackscreen/*.xml` + 32 个 `res/*`。
- MIUI 自定义属性（`nabilaba_toapp`、`MiuiClockMode` 等）在 apktool 解码时保留为未知属性，不影响对比。
- 方法级 diff 基于 smali 文本归一化，能剔除重编译噪声，但无法还原 Java 源码语义；具体行为需结合 `MiuiGlobalActionsDialog` 等类的 smali 阅读。
- 签名对比只做「证书一致 / META-INF 字节一致」判断；V2/V3 签名块是否随内容重算需用 `apksigner verify` 另行确认。

## 5. 验证清单

1. `wc -l new_classes.txt` = 527；`wc -l differ_classes.txt` = 202。
2. `python3 analyze_methods.py` 输出 `real=69`。
3. `python3 vals_compare.py` 输出 `values +57 -1 ~54 ; res +72 -3 ~79`。
4. `grep -c '^##########' rdiff/res_text.diff`（若生成）应与 res_mod 数一致。
5. 装机侧：长按磁贴出编辑/分组面板；电源菜单出现滑动重启/关机/Recovery/Fastboot；音量/亮度面板呈胶囊圆角；MiPlay/媒体面板大屏布局正常。
